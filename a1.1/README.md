# German A1.1 — vocabulary by unit

Study notes built from the official A1.1 vocabulary sheets, one folder per unit. Each unit is
self-contained: where a sheet repeats an item from an earlier unit, it is repeated here too, so you
can revise a single unit without cross-referencing.

| Unit | Theme |
| ---- | ----- |
| `unit-01/` | greetings, names, where you're from |
| `unit-02/` | family, articles, personal details |
| `unit-03/` | shopping, food and drink, eating out |
| `unit-04/` | the home: rooms, furniture, describing and locating things |
| `unit-05/` | daily routine, telling the time, making plans |
| `unit-06/` | weather, free time, hobbies and opinions |
| `unit-07/` | professions, abilities, the perfect tense |

Each unit folder has its own `README.md` mapping files to the sheet sections they cover.

## Conventions

- Tables are `English | Deutsch`, or `Level | English | Deutsch` where the sheet gives separate
  informal (*du*) and formal (*Sie*) forms.
- Articles are printed exactly as the sheets print them.
- The German is entirely from the sheets. English translations and short grammar notes are added,
  and anywhere a table goes past what the sheet lists, the file says so.
- Each unit README notes the section numbers its sheet skips.

## Relationship to `a1/`

`a1/` holds the flat comma-separated word pool that the project `CLAUDE.md` feeds to the
conversational practice agent. These unit folders are the fuller reference notes. They are not
currently wired into that pool.
