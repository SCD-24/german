# Politeness

Source: Unit 1.9.

| English                 | Deutsch             |
| ----------------------- | ------------------- |
| thanks / thank you      | danke / danke schön |
| please / here you go    | bitte / bitte schön |
| don't mention it        | nichts zu danken    |
| you're welcome / gladly | gern geschehen      |
| excuse me / sorry       | Entschuldigung      |
| I'm sorry               | tut mir leid        |

*bitte* does double duty: **please** when you ask for something, **you're welcome** or **here you are**
when you hand something over.

*Entschuldigung* gets someone's attention or excuses a small thing. *Tut mir leid* apologises for
something that actually happened.
