# Pronouns and formality

Source: Unit 1.7.

| Deutsch     | English                |
| ----------- | ---------------------- |
| ich         | I                      |
| du          | you (singular informal)|
| er, sie, es | he, she, it            |
| wir         | we                     |
| ihr         | you (plural informal)  |
| sie         | they                   |
| Sie         | you (formal)           |

*sie* (they) and *Sie* (formal you) differ only by the capital letter, and take the same verb form.

## du or Sie

| English                             | Deutsch               |
| ----------------------------------- | --------------------- |
| to address someone as *du*          | duzen                 |
| to address someone as *Sie*         | siezen                |
| You can use *du* with me.           | Du kannst mich duzen. |
