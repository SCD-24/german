# Names and introductions

Source: Unit 1.2.

| Level    | English              | Deutsch            |
| -------- | -------------------- | ------------------ |
| neutral  | My name is ...       | Mein Name ist ... .|
| informal | What is your name?   | Wie ist dein Name? |
| neutral  | I am called ...      | Ich heiße ...      |
| informal | What are you called? | Wie heißt du?      |
| formal   | What are you called? | Wie heißen Sie?    |

| English        | Deutsch      |
| -------------- | ------------ |
| the name       | der Name     |
| the first name | der Vorname  |
| the last name  | der Nachname |
| to be called   | heißen       |

*heißen* keeps its *-ß*, so the *du* form takes only *-t*: **du heißt**, not *du heißst*.
