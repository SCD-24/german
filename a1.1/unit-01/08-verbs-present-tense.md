# Verbs — present tense

Source: Unit 1.8. The sheet lists only the three infinitives; the conjugation table below fills in the
regular pattern.

| English      | Deutsch |
| ------------ | ------- |
| to cook      | kochen  |
| to do / make | machen  |
| to come      | kommen  |

Drop *-en* from the infinitive and add the ending:

| Person    | Ending | kochen | machen | kommen |
| --------- | ------ | ------ | ------ | ------ |
| ich       | -e     | koche  | mache  | komme  |
| du        | -st    | kochst | machst | kommst |
| er/sie/es | -t     | kocht  | macht  | kommt  |
| wir       | -en    | kochen | machen | kommen |
| ihr       | -t     | kocht  | macht  | kommt  |
| sie/Sie   | -en    | kochen | machen | kommen |

*Ich komme aus ...* and *Woher kommst du?* from 1.4 are this pattern in use.
