# How are you

Source: Unit 1.5.

| Level    | English         | Deutsch            |
| -------- | --------------- | ------------------ |
| casual   | How's it going? | Wie gehts?         |
| informal | How are you?    | Wie geht es dir?   |
| formal   | How are you?    | Wie geht es Ihnen? |

*Wie gehts?* is the contraction of *Wie geht es?* (usually written *Wie geht's?*).

## Answers

| English   | Deutsch       |
| --------- | ------------- |
| good      | gut           |
| very good | sehr gut      |
| bad       | schlecht      |
| very bad  | sehr schlecht |
| so-so     | soso          |
