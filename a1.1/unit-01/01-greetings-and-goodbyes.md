# Greetings and goodbyes

Source: Unit 1.1.

| English      | Deutsch         |
| ------------ | --------------- |
| Hello!       | Hallo!          |
| Hi!          | Hi!             |
| Good day!    | Guten Tag!      |
| Good morning!| Guten Morgen!   |
| Good evening!| Guten Abend!    |
| Bye!         | Tschüss!        |
| Goodbye!     | Auf Wiedersehen!|

*Tschüss* is informal, *Auf Wiedersehen* formal.

## Times of day

| English     | Deutsch    |
| ----------- | ---------- |
| the day     | der Tag    |
| the morning | der Morgen |
| the evening | der Abend  |

The greetings are just *guten* + one of these nouns.
