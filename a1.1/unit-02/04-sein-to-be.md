# sein — to be

Source: Unit 2.5.

| Deutsch       | English          |
| ------------- | ---------------- |
| sein          | to be            |
| ich bin       | I am             |
| du bist       | you are          |
| er, sie, es ist | he, she, it is |
| wir sind      | we are           |
| ihr seid      | you are (plural) |
| sie sind      | they are         |
| Sie sind      | you are (formal) |

Completely irregular — none of the forms come from the infinitive, so this one is memorised, not
derived. *sie sind* and *Sie sind* are identical apart from the capital.
