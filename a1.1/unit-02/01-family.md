# Family

Sources: Unit 2.1, Unit 2.12.

## Immediate family

| English           | Deutsch         |
| ----------------- | --------------- |
| the mother        | die Mutter      |
| the father        | der Vater       |
| the parents       | die Eltern      |
| the husband / man | der Mann        |
| the wife / woman  | die Frau        |
| the children      | die Kinder      |
| the son           | der Sohn        |
| the daughter      | die Tochter     |
| the brother       | der Bruder      |
| the sister        | die Schwester   |
| the siblings      | die Geschwister |

*die Kinder* is the plural of **das Kind**. *die Eltern* and *die Geschwister* only exist as plurals.

## Grandparents and extended family

| English                   | Deutsch                 |
| ------------------------- | ----------------------- |
| the grandpa / grandfather | der Opa, der Großvater  |
| the grandma / grandmother | die Oma, die Großmutter |
| the grandparents          | die Großeltern          |
| the aunt                  | die Tante               |
| the uncle                 | der Onkel               |
| the cousin (female)       | die Cousine             |
| the cousin (male)         | der Cousin              |

*Opa* and *Oma* are the everyday words; *Großvater* and *Großmutter* are the formal ones.

## Asking about someone's family

| Level    | English                    | Deutsch                             |
| -------- | -------------------------- | ----------------------------------- |
| informal | Are you married?           | Bist du verheiratet?                |
| formal   | Are you married?           | Sind Sie verheiratet?               |
| informal | Do you have children?      | Hast du Kinder?                     |
| formal   | Do you have children?      | Haben Sie Kinder?                   |
| neutral  | I have a son / a daughter. | Ich habe einen Sohn / eine Tochter. |
| neutral  | I have two children.       | Ich habe zwei Kinder.               |
| neutral  | I have no children.        | Ich habe keine Kinder.              |

*haben* takes the accusative, which is why masculine *ein* becomes **einen** Sohn while feminine
*eine* Tochter is unchanged.
