# Personal details and forms

Sources: Unit 2.9, Unit 2.13.

## Phone number, and asking again

| English                       | Deutsch                           |
| ----------------------------- | --------------------------------- |
| What is your phone number?    | Wie ist deine Telefonnummer?      |
| What is your phone number?    | Wie lautet deine Telefonnummer?   |
| Pardon? / Sorry, what?        | Wie bitte?                        |
| Could you repeat that please? | Können Sie das bitte wiederholen? |

*lauten* is the more formal verb for how a number or name "goes". Both questions above are informal
(*deine*); the repeat request is formal (*Sie*).
