# Languages

Source: Unit 2.6.

| English          | Deutsch      |
| ---------------- | ------------ |
| the language     | die Sprache  |
| to speak         | sprechen     |
| a little / a bit | ein bisschen |

| English    | Deutsch       |
| ---------- | ------------- |
| German     | Deutsch       |
| English    | Englisch      |
| French     | Französisch   |
| Spanish    | Spanisch      |
| Portuguese | Portugiesisch |
| Japanese   | Japanisch     |

Language names are capitalised and take no article after *sprechen*: **Ich spreche ein bisschen
Deutsch.**

*sprechen* changes its stem vowel in the *du* and *er* forms (not shown on the sheet):
**du sprichst**, **er/sie/es spricht**.
